# Savith.Online

Source for [savith.online](https://savith.online) - my personal site.

## What's here

A simple static site, no build step or framework:

- `index.html` - home / intro
- `about.html` - about me
- `projects.html` - things I've built
- `articles.html` - writing, with individual posts under `articles/`
- `assets/` - stylesheet and images

Hosted on GitHub Pages, with the `CNAME` file pointing it at the custom domain.

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server.
